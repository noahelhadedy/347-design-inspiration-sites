# Contributing

Thanks for wanting to add a design inspiration site. Keep it simple — open a Pull Request editing `README.md` (and `design-inspiration-notion.csv` if you can).

## Criteria

A site must be:

1. **Actually inspiring** — a gallery, showcase, pattern library, or reference source people return to for design ideas. Not a single portfolio or blog post.
2. **Live and maintained** — the link works and the site is still updated.
3. **Useful to a general audience** — web, product, UI, or visual design. Not a niche personal page or dead project.
4. **Not already listed** — check the table first with Ctrl+F.

## Format

Add the site at the end of the table. Use this format:

```
| <next #> | [Site Name](https://example.com) | One-line description |
```

- Keep descriptions under ~80 characters and **no trailing period** (unified style).
- Lead with what it is, not marketing language ("Curated gallery of dark-themed sites" beats "The best inspiration ever").
- Use the official homepage URL — not a mirror or affiliate link.

If you can, add the same row to `design-inspiration-notion.csv` so the spreadsheet stays in sync.

## Process

1. Fork the repo.
2. Edit `README.md` (and the CSV if possible).
3. Open a PR with a short justification — a link to the site and one sentence on why it fits.
4. One site per PR (makes review easier).

Removals (dead links, sites gone paid-only or offline) are welcome too — same flow.

## Not accepted

- Dead links or abandoned sites.
- Affiliate links, referral codes, SEO spam, or self-promotion.
- Single portfolios, one-off blog posts, or thin content farms.
- NSFW or low-quality content.
